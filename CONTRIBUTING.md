# Contributing a pack

1. Copy the format from `skill/civic-navigator/references/pack-format.md`.
2. Create `skill/civic-navigator/packs/<place>-<topic>.md` (for example `kenya-agriculture.md`).
3. Add 5 to 15 schemes. For each one, find a **Tier 1 (official)** source. No Tier 1 source, no entry.
4. Put every deadline, amount or window that only a secondary source supports under "Facts NOT confirmed by an official source".
5. Set "Last verified" only when you actually re-checked the official page.
6. Open a pull request with the official links in the description.

Never include personal data or content copied from login-only pages.
